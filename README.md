# Sistema Simples de Biblioteca - Prática de Banco de Dados

Projeto desenvolvido para revisar fundamentos de Banco de Dados.

## Conceitos aplicados

- Modelagem relacional
- Chave primária
- Chave estrangeira
- Integridade referencial
- Consultas com JOIN
- Filtro com WHERE
- Relacionamento 1:N

## Estrutura

- Script de criação de tabelas
- Inserts de exemplo
- Consultas para prática

Este projeto pode ser utilizado como base para exercícios introdutórios em Banco de Dados.
